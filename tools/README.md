# Tools Directory

This directory contains utility scripts and tools for the POFJSP system.

## Reporting Tools (`reporting/`)

- `enhanced_latex_generator.py` - Advanced LaTeX report generator with comprehensive visualizations
- `latex_report_generator.py` - Basic LaTeX report generator
- `comprehensive_benchmark.py` - Comprehensive benchmarking system
- `run_production_benchmark.py` - Production-level benchmark runner

## Usage

```bash
# Generate comprehensive PDF report with visualizations
cd tools/reporting
python enhanced_latex_generator.py

# Run basic benchmarks
python comprehensive_benchmark.py

# Run production benchmarks
python run_production_benchmark.py
```
